# 💊 İlaç & Prospektüs Rehberi

U.S. FDA ve resmi farmakope veri tabanı ile etken maddeler, prospektüs özeti, kullanım uyarıları ve açık bildirilmiş yan etki analitiği.

## ✨ Özellikler
- **%100 Sunucusuz & Bağımsız:** Herhangi bir backend veya proxy gerektirmez; tarayıcı üzerinden doğrudan açık API'lerle çalışır.
- **Açık openFDA Entegrasyonu:** Dünya genelindeki tüm FDA onaylı etken maddeleri canlı sorgular ve resmi advers reaksiyon raporlarını analiz eder.
- **Türkiye Klinik Farmakope Desteği:** Calpol, Parol, Pedifen, Dolven, Arveles, Augmentin gibi popüler yerel ilaç ve etken maddelerin doğrulanmış prospektüs özetlerini sunar.
- **LocalStorage & Mistral AI Arayüzü:** Hızlı, responsive ve şık kullanıcı deneyimi.

## 🚀 Hızlı Başlangıç
1. Bu repoyu klonlayın:
   ```bash
   git clone https://github.com/melihkarasu/ilac-rehberi.git
   cd ilac-rehberi
   ```
2. `index.html` dosyasını doğrudan herhangi bir modern web tarayıcısında açın veya GitHub Pages üzerinden canlı kullanın.

## 🔑 API & Veri Kaynakları
Bu uygulama herhangi bir özel API anahtarı veya yetkilendirme **gerektirmez**:
- **U.S. openFDA API:** Kamu erişimine açık ve ücretsizdir (`https://api.fda.gov/drug/`).
- **Resmi Farmakope & MedDRA Sözlüğü:** İstemci tarafında yerel olarak derlenmiş açık veri setleriyle zenginleştirilmiştir.

## 🛠️ Teknik Detaylar
- **Styling:** Tailwind CSS
- **Design System:** Mistral AI Design System
- **Storage:** Browser LocalStorage API
- **API Source:** openFDA Drug Label & Event API
